## Claude 建議、使用中的暫定規則

| 項目 | 暫定值 | 備註 |
|---|---|---|
| P0 區域 | 只有主峰，8 個建築槽 | 企畫書表格中的區域加成 P1 再做 |

| 開局物資 | 靈石 300、糧食 200、石材 80、靈木 80、藥草 20 | 靈木原為 60，瀏覽器實測時無法同時修大殿＋建三座生產建築，調為 80 |
| 外門 | 12 人；分工：耕作、採石、伐木、委託（每人每月靈石 2）、修煉 | |
| 糧食 | 外門每人每月 1；內門每 2 人 1；築基以上不吃 | 缺糧兩個月且滿意度低於 20 開始有人離開，不會死人 |
| 消耗順序 | 糧食 → 維護 → 築基丹 → 聚氣丹 → 煉丹材料；只扣月初庫存 | 本月產出下月才能用（審閱 C5） |

| 丹方 | 聚氣丹、回春丹開局即會；築基丹丹方由荒廢洞府首次通關取得 | 原提案為兩種丹方，為了讓「生命低時用藥」策略可用，加入回春丹 |
