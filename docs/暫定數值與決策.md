- 一開始護衛委託報酬太高（剿山賊寨 90 靈石），委託流 100 年後囤了 3 萬靈石；已降到 50。
- 自動玩家會把主角搬到後山，但聚靈陣蓋在主峰，結果後山靈氣不夠築基、卡了 80 年。這是自動玩家的策略錯誤（遊戲會清楚顯示原因），已改成搬到靈氣最高的區域並在後山補蓋聚靈陣。
- 資源全部歸零的宗門只靠勞務委託恢復時，原本糧食回升太慢；修渠的報酬改成每人糧食 4。
