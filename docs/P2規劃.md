## 1. P2 要做什麼（企畫書 §18）

範圍【企畫書】：
- 境界開放到化神。
- 建築湊滿 19 種目標。
- 主要勢力 6–8 個。
- 進階探索。
- 聯盟與吞併。
- 壽元與繼承。
- 主要正式美術。

驗收【企畫書】：
1. 從開局可以完整玩到化神。
2. 勢力有看得到的發展，而且資源有限。
3. 戰爭有預警。
4. 長期存檔能繼續玩。
5. 至少用三種不同路線試玩，記錄時數、卡關點和重複操作，並據此調整。
6. 「八十小時」的目標沒有實測前，不能宣稱已達成。

P1 留給 P2 的問題：
- 委託路線後期靈石、聲望大量累積，沒有地方花。
- 大殿升級後，全景圖沒有變化。
- 手機直拿版。
- 主角金丹立繪、大比場景沒有位置放。

P2 **不做**（留給 P3 以後）：煉虛以上境界、飛升、上界。

## 4. 各系統設計【Claude 建議，全部為暫定】

### 4.1 壽元與繼承（批次 A）
- 各境界壽元上限（暫定）：
  - 凡人／煉氣 100 歲
  - 築基 200 歲
  - 金丹 400 歲
  - 元嬰 800 歲
  - 化神 1,500 歲
- 剩 20% 和 10% 時跳出預警【企畫書】。
- 延壽途徑：
  - 延壽丹：新配方，材料貴，一生最多吃兩次。
  - 突破到下一個大境界。
  - 秘境裡的特殊機緣。
- 弟子壽終：會老死，月報通知。職位、丹爐、靈獸自動空出來。
- 掌門繼承：
  - 可以從內門中指定一位親傳弟子當繼承人。
  - 主角壽終時，沒有指定的話，跳出繼承選擇事件【企畫書】。
  - 宗門進度全部保留，不會刪檔。
  - 新掌門沿用宗門傳承，但境界和技藝是他自己的。
- 祖師殿（主峰）：
  - 供奉歷代掌門。
  - 每供奉一位，全宗修煉速度 +3%，最多 +15%。
  - 2 級可以「祖師顯靈」，一次性救回一場失敗的突破。

### 4.2 連續推進與自動停止（批次 A）
- 推進按鈕旁加「推進到……」：可選 3 個月、6 個月、12 個月，或推進到某個條件為止。
- 一定會停下的情況：
  - 招生
  - 宣戰預警
  - 壽元預警
  - 突破條件達成
  - 資源快用完
  - 大比、競標開始
- 各項停止條件可以在設定頁開關【企畫書 §17】。
- 每個月仍然逐月結算、逐月存檔，結果和一個月一個月按完全一樣。

### 4.3 元嬰、化神（批次 B）
- 元嬰、化神各分前期、中期、後期、圓滿。
- 大突破需要：
  - 修為
  - 功法領悟到「大成」以上
  - 靈氣環境：聚靈陣 3 級，洞府 3 級
  - 材料：元嬰需要「凝嬰丹」，化神需要「化神丹」或秘境機緣
- 突破失敗：
  - 元嬰：重傷、修為倒退。
  - 化神：重傷、修為倒退，並且**有死亡風險**。
  - 死亡機率在突破前明示【企畫書】，詳見問題 Q3。
- 後期大額花費管道（解決 P1 靈石累積的問題）：
  - 凝嬰丹、化神丹的材料只能高價購買或從秘境取得。
  - 建築 3–4 級、護山大陣維護費高。
  - 宗門晉階：大殿 4–5 級，提高勢力地位，影響外交。

### 4.4 勢力與外交（批次 C）
- 鄰近 3 宗用完整模擬；另加 3–5 個遠方勢力，用簡化結算。
- 每派都有：
  - 資源帳本
  - 領地（資源據點）
  - 人口
  - 實力
  - 性格：守成、經商、好戰、求道、重承諾
  - 當前目標，例如擴軍、缺丹、爭礦
- 每月選少量行動，缺料不能建設，兵力不足不會隨便開戰【企畫書】。
- 外交：
  - 好感：送禮、交易可以增加。
  - 信任：要靠履行約定，禮物買不到【企畫書】。
  - 互不侵犯、聯盟：有義務（被打時要出兵或出資）、期限、退出代價。
- 議事堂（主峰）：
  - 解鎖外交條約。
  - 提高可同時維持的條約數。
  - 外事執事在這裡辦公。

### 4.5 衝突、戰爭與吞併（批次 D）
- 資源據點：
  - 靈礦、藥田等據點散在地圖上。
  - 可以派隊伍爭奪，結果是自動戰鬥加結算。
- 宣戰：
  - 需要理由，例如爭奪據點、好感太低、對方目標是擴張。
  - 宣戰後有 3–6 個月準備期。
  - 準備期間玩家可以求援、談判、撤離資產【企畫書】。
- 山門戰：
  - 用多場自動戰鬥決定結果。
  - 護山大陣可以提高防守方的勝率。
  - 戰敗不會滅宗：損失資源、建築損毀待修、割讓據點（企畫書：損毀先停用待修，不直接抹除）。
- 吞併：
  - 擊敗並使對方投降後，可以選擇收為附屬或吞併。
  - 吞併會得到對方的人和地。
  - 代價是忠誠度低、維護費變高，對方的傳承也可能和我宗衝突【企畫書】。
- 戰爭死亡尺度見問題 Q4。

### 4.6 進階探索與倉庫（批次 E）
- 新秘境：
  - 宗門試煉：用來培養弟子，失敗不會死。
  - 大型上古秘境：多層，每層通關可以暫停下次再來。
- 事件池：重複探索時，路線和事件會隨機變化；獨特獎勵只給一次【企畫書】。
- 倉庫：
  - 各資源有庫存上限，倉庫可以提高上限。
  - 丹藥放在倉庫裡不會過期（P2 才加保存期限的話，倉庫可以延長）。

## 7. 風險與提醒

- **最大風險是節奏**：「玩到化神」可能要好幾百遊戲年。每批都會用自動玩家跑 300 年模擬，記下各境界的到達年份。但真人玩起來的時數，還是要你試玩才知道。
- 勢力和戰爭牽涉的系統最多，批次 C、D 會用最多時間；每批合併前都會先跑長期模擬，確認勢力不會失控或全滅。
- 每批都會改存檔格式，會附舊存檔遷移和測試。0.4.x 的存檔可以直接升級。
- P1 總檢查找到的問題已經在 0.4.5 修完。開始批次 A 之前，建議你先實際玩一次 0.4.5，回饋越早，P2 越少改兩次。
