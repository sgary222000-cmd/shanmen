## 與審閱提案不同的地方

- 建築由 5 種改為 7 種逐步開放（使用者要求）。
- 丹方多一種「回春丹」，讓「生命低時用藥」的戰鬥策略有東西可用。
- 新增「山下商隊」簡易交易：模擬時發現靈石是唯一瓶頸、石材靈木大量堆積，依企畫書 §8「物資交換作為恢復途徑」加入，有每月限額與買賣價差。
- 開局靈木由 60 調為 80：瀏覽器實測時，修完大殿後木材不夠蓋第三座生產建築。

## 已知問題與限制

- P0 每種建築只能蓋一座；區域只有主峰。
- 自動玩家的策略很簡單；模擬里程碑（約第 12–19 年築基）不代表真人遊玩時數。
- 測試環境中，Playwright 上傳「中文檔名」的檔案時瀏覽器收不到檔案（連最簡單的 HTML 檔案欄位也一樣），判斷是測試環境問題。為保險起見，匯出存檔的檔名改為只用英數字。真實瀏覽器匯入中文檔名的情況尚未驗證。
- 尚未在手機或小螢幕上檢查版面（企畫書以電腦瀏覽器優先）。
