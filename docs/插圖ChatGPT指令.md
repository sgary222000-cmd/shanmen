# 插圖 ChatGPT 指令

對應 [插圖製作需求](插圖製作需求.md)。每張圖一段指令，整段複製貼給 ChatGPT 即可。

## 使用方式

1. **先貼「共同風格」那段**，再貼單張的指令。同一個對話裡連續做，風格比較一致。
2. ChatGPT 出圖只有三種尺寸：橫 1536×1024、直 1024×1536、方 1024×1024，做不出遊戲要的寬幅比例。所以指令裡會請它**把重要內容集中在中間**，拿到圖後再裁切（見各張的「裁切」）。裁切可用小畫家、手機相簿或 [Photopea](https://www.photopea.com/)（免費網頁版）。
3. 裁切後全景只有 1536 寬，比文件建議的 2400 小。先拿來當樣稿放進遊戲看效果沒問題；正式版若嫌不夠清楚，可以再用放大工具處理（建議）。
4. 圖裡若出現文字、印章或邊框，請它重畫：「請移除畫面中所有文字、印章與邊框，其他保持不變」。
5. 存檔用英文檔名，例如 `panorama.png`，交給我放進遊戲。

## 共同風格（每次對話開頭先貼）

```
接下來我要請你畫一系列遊戲插圖，全部遵守以下風格：
- 精緻國風，青綠山水畫風格（石青、石綠為主色，搭配雲霧留白），但用現代數位繪畫的細緻度呈現。
- 建築細緻（木構斗拱、青瓦、石階、欄杆），自然光影，晨光或柔和側光。
- 題材：一個沒落的修仙宗門，殘破但可以修復，仍保有仙山山門的氣勢。
- 嚴格禁止：畫面中不得出現任何文字、書法、印章、落款、標題、按鈕、邊框、浮水印。
- 不要畫人物，除非我特別要求。
請回答「了解」，等我給第一張圖的需求。
```
