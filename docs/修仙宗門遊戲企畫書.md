## 2. 遊戲定位

玩家繼承一座衰敗宗門，恢復生產、招收弟子、修復傳承，逐步建立能在掌門閉關期間自主運作的組織。宗門支援主角突破，主角為宗門取得更高階資源與生存空間。弟子成長為執事、長老與繼任掌門，最終形成跨越人界與上界的傳承。

目標體驗：親手建成宗門、發掘人才、完成產業布局、見證數代弟子成長，並與具有自身利益的勢力周旋。

不依賴動畫。透過場景插圖、人物立繪、建築外觀階段、戰報、音效選配與清楚的數值回饋呈現變化。

## 3. 核心循環與時間

核心循環：安排工作與行程 → 預覽收支 → 推進一月 → 結算生產與修煉 → 處理事件 → 建設、培養、交易、探索 → 再次安排。

一個遊戲月是基本世界結算單位，十二月為一年。沒有必須等待的現實倒數；關閉遊戲不直接增加人物年齡，也不讓其他宗門持續奪取領地。

初始結算順序：
1. 檢查行程、工作與建造是否合法，顯示預計消耗。
2. 按既定優先順序扣除維護與生產投入；不足項目停工並提示。
3. 結算生產、建造與研究進度；同月產出不得反覆充當其他生產投入。
4. 結算修煉、療傷、教學、人物年齡與壽元預警。
5. 結算已確認的派遣、戰鬥與探索結果。
6. 電腦宗門各執行有限次合法行動，更新市場與情報。
7. 產生事件、檢查警報，寫入月報並自動存檔。

重大事件暫停連續推進。宣戰、重要人物危急、突破條件達成、倉庫不足等可設定停止條件。不得在事件未處理時重複結算月份。

離線加成提案：離線滿一小時取得一份休養加成，上限八份；每個遊戲月最多消耗一份，使基礎生產增加10%，不增加稀有物品、不影響戰鬥。使用者可關閉。沒有加成仍可完整遊玩。時間倒退不補發，異常時間差按上限處理。

## 4. 長期節奏

完整內容以八十小時以上首次遊玩為設計願景，不能作為未經測試的時數保證。時間來自經營決策、傳承發展與世界變化，不以重複點擊或現實等待填充。

短期目標：一批丹藥、一次建設、一次招募。中期目標：培養專業人才、形成產業鏈、取得據點。長期目標：大境界突破、宗門升階、建立聯盟與飛升。

每個大境界增加至少一項實質經營或戰鬥選擇。不得只換資源名稱與放大數字。允許自動生產、工作範本、秘境派遣與連續月份推進，減少成熟宗門的重複操作。

初始人界平衡可讓抵達化神跨越數百遊戲年，但實際年月與操作時數須由測試調整。顯示資源瓶頸與突破缺項，避免玩家不知道為何停滯。

## 5. 主角修仙

完整境界：煉氣 → 築基 → 金丹 → 元嬰 → 化神 → 煉虛 → 合體 → 大乘 → 渡劫。飛升後上界境界另行設計，不能僅複製人界數值。

煉氣分層、其餘分前中後期與圓滿為初始提案。小階段主要累積修為；大突破需要修為、功法領悟、靈氣環境與對應材料。突破前顯示機率、影響因素、失敗代價與保護措施。

突破失敗原則上造成受傷、修為損失或材料消耗；重要人物死亡風險必須事前明示，不得隱藏突然觸發。

主角每月一項主要行程：閉關、授課、探索、煉丹、煉器、研究、交涉或療傷。日常查看與下達宗門命令不消耗主角行程；親自參與的活動需要行程。閉關可預先設定月數並允許中斷，代價在開始前顯示。

## 6. 壽元與傳承

人物有年齡與境界壽元，突破可提升壽元上限。壽元剩餘20%與10%時預警；重要角色提供丹藥、突破、特殊任務等挽救途徑，但不保證所有角色必能長生。

主角壽終前可指定繼承人；未指定則開啟繼承選擇事件。宗門進度保留，不能無預警直接刪檔。主角飛升後由繼任者管理人界，同時保留上界主角線。

## 7. 區域與建築

山峰與地區固定，各區有有限建築槽位、環境標籤與靈氣容量。擴張透過修復道路、購入土地、探索與取得領地。顯示地區加成與建造限制。

|---|---|---|
| 主峰 | 靈氣穩定、位置珍貴 | 大殿、藏經閣、祖師殿 |
| 外山 | 容易擴張 | 弟子居所、倉庫、工坊 |

基礎設施：宗門大殿、弟子居所、靈田、藥園、採石場、靈木場、倉庫、聚靈陣、洞府、藏經閣、演武場、煉丹房、煉器坊、符陣閣、靈獸苑、議事堂、坊市、護山大陣、祖師殿。十九種為內容目標，不要求一次實作。

升級同時提供產能、席位、配方或新功能。高階設施需要人才與研究，不能一律綁定主角境界。拆除、遷移與退還規則應在操作前顯示。建築損毀先停用與待修復，普通衝突不直接抹除全部投資。

## 8. 經濟與生產

主要資源：靈石、靈木、石材、靈礦、藥草、糧食、靈氣、丹藥、法器與符籙。聲望、研究與宗門貢獻分別作為進度或管理指標，不與貨幣混用。

靈氣為區域供應容量，修煉與部分設施占用，避免同一份靈氣無限制重複使用。靈石支付交易、維護與部分生產。糧食主要供低階弟子，隨修為提升降低需求。

產業鏈範例：藥田 → 藥草 → 煉丹 → 修煉與交易；靈礦 → 精煉 → 法器 → 戰鬥與出售；靈木與靈墨 → 符紙 → 符籙 → 探索消耗。

生產受人員、設備、配方與投入限制。介面顯示每月毛產出、消耗、淨變化及預計耗盡月份。允許指定庫存下限與重複配方。缺料時停止對應配方，不產生負庫存。

市場具有有限貨量、買賣差價與有上下限的價格波動。避免無限買賣套利。初期提供基礎委託與物資交換作為恢復途徑，資源短缺不應造成無解死局。

## 9. 弟子與組織

外門以群體表示人數、分工、生活與培養狀態；晉升時生成或選定具名人物。內門、親傳與長老逐人管理。

個別人物資料：穩定識別碼、姓名、肖像、年齡、境界、修為、靈根、性格、忠誠、健康、技藝、功法、裝備、關係與職位。

靈根影響效率與親和，不是唯一價值。專業天賦可以讓普通修煉資質者成為關鍵人才。改命機緣稀少、有前置條件，不能反覆無成本洗資質。

招募來源：定期山門招生、城鎮尋訪、事件救助、散修投靠與附屬勢力推薦。提供候選人比較與維持成本。

晉升流程：外門 → 內門 → 親傳或專業執事 → 長老。職位與弟子身分分開；高境界不必自動成為管理者。重要職位包括傳功、煉丹、煉器、庶務與外事。

忠誠與滿意度受待遇、傷亡、任務與宗門理念影響，變動提供原因。叛逃有預警與處理機會。人物劇情以簡短事件為主，服務經營選擇。

## 11. 自動回合戰鬥

初始採五人隊伍，靈獸占用規則須在御獸模組實作前定案。玩家配置前後排、功法、法寶、消耗品與策略。一般戰鬥不要求逐回合操作。

基礎屬性：生命、攻擊、防禦、速度、命中、抗性。依速度決定行動，平手用穩定規則判定。提供回合上限與平局處理，防止無限戰鬥。

策略例：優先攻擊低生命敵人、保護指定隊友、生命低於門檻時用藥、保留靈力使用關鍵技能。規則需可讀，先提供預設方案再開放細調。

戰鬥顯示隊伍插圖、生命與狀態、重點戰報、完整紀錄、快速結算。結算包括獎勵、消耗、傷勢與失敗原因。允許撤退，代價事前顯示。

戰力數字僅作參考，不能取代屬性與策略結算。隨機使用可保存的種子，避免讀檔或介面重開無限重擲結果。

## 12. 探索

秘境首次以節點構成：入口 → 分岔 → 資源/事件/敵人 → 首領或關鍵機緣 → 出口。顯示已知風險、物資、隊伍與撤退條件。

探索需要主角行程或指定隊伍，不能同一人物同時閉關與出征。已完成秘境在達到探索度後解鎖派遣，收益低於首次獎勵並消耗遊戲月份與補給。

初始類型：廢棄洞府、古修遺跡、靈獸山谷、地下靈礦、宗門試煉與大型上古秘境。重複內容使用事件池與不同路線，獨特傳承首次獎勵不可無限複製。

## 13. 電腦宗門與世界

電腦宗門由本機規則驅動，不需要付費生成式 AI。每派有資源帳本、領地、傳承、人口、實力、外交關係、行事性格與當前目標。

每月依生存、發展、防禦與擴張優先度選擇少量行動；缺料無法建設，兵力不足不隨意開戰。遠方勢力可用簡化結算，鄰近勢力使用較詳細模擬。

六至八個主要勢力為人界內容目標，可另有抽象小派。性格包括守成、經商、好戰、求道與重視承諾。行為留下情報，例如招募、缺丹、擴軍與爭奪礦場。

外交包括好感、信任、利益衝突、交易、互不侵犯與聯盟。聯盟有義務、持續時間與退出代價。不得僅靠贈禮無上限購買所有勢力支持。

前期：大比、競標、資源據點衝突。中期：附屬勢力、區域聯盟與有限戰爭。後期：山門戰、吞併與滅宗。

攻打山門需要宣戰條件與準備期。玩家有預警、求援、談判與撤離資產機會。吞併帶來忠誠整合、維護、傳承衝突等治理成本，擴張不應形成毫無代價的滾雪球。

## 14. 開局與階段目標

開局為沒落宗門遺產：殘破大殿、少量物資、有限外門弟子、一份主傳承與尚待修復的山門。玩家命名主角與宗門，選擇主傳承。

引導任務：查看收支 → 指派生產 → 安排主角修煉 → 推進首月 → 修復設施 → 招收第一位內門弟子 → 完成初次探索與戰鬥 → 建立穩定丹藥供應。

不強制每個新存檔重看長篇故事。初期保護期不觸發滅宗級攻擊；具體保護期限可調整且清楚提示。

宗門階段可採破敗山門、地方小宗、區域宗門、一方大宗、聖地與跨界道統。升階條件同時考慮人才、經營與傳承，不只計算主角戰力。

## 15. 飛升與雙界

人界宗門由繼任掌門與長老維持，上界主角建立新據點。玩家可切換兩界。兩界共用全局月份結算，避免切換介面造成額外產出。

跨界資源不直接自由流通，透過有限額度、建設與事件解鎖傳送。保留人界弟子的成長與飛升途徑，避免飛升後人界完全失去價值。

長期目標包括飛升、天下第一宗、完整傳承、弟子世代成就與探索祕密。達成目標不強制結束存檔。

## 16. 介面與美術

主要頁面：宗門總覽、區域建設、主角、弟子、產業、藏經與研究、世界地圖、探索、外交、戰報與設定。畫面持續顯示年月、主要資源、警報與推進月份按鈕。

宗門主畫面為可點擊區域插圖；列表管理提供排序、篩選與批次指派。確認視窗只用於重要或難以復原的操作。文字可調大小，顏色以外另用圖示表示警報。

美術方向提案：工筆重彩人物、青綠山水宗門、厚塗秘境、精緻器物。介面採墨青、暖白與舊金，確保長時間閱讀清楚。圖片內不嵌入按鈕文字。

先製作宗門全景、人物立繪與秘境各一張樣稿，確認風格後批量製作。正式素材需有合法使用權並記錄來源；本企畫尚未包含成品插圖。

素材目標：宗門全景四個發展階段；六類區域背景；十九種建築各二至三種外觀；重要角色專屬立繪；一般人物肖像庫；秘境背景與器物圖示。以上為累積目標，按版本配置，不要求核心試玩版全部完成。

美術品質重點：人物比例、衣料與建築細節一致；宗門成長可見；避免風格混雜、模糊圖像與圖文遮擋。技術上使用適當尺寸、壓縮與按需載入，不能為追求清晰一次載入所有大圖。

模組分離：時間結算、經濟、人物、建築、戰鬥、探索、勢力、事件、存檔與介面。功法、配方、建築與事件採獨立資料定義及穩定識別碼。畫面重繪不得改變世界狀態。

設定提供音量、字體、加速結算、通知、自動停止與離線加成開關。開發測試工具與正常玩家介面分開。

## 18. 開發階段與驗收

### P0：核心試玩版
範圍：單區域、五種建築、煉氣與築基、基礎招募和工作、月結算、一個秘境、一次自動戰鬥、存讀檔。開局先完成劍修，其他傳承明示尚未開放。

驗收：新存檔可完成「生產 → 建設 → 培養 → 探索 → 戰鬥 → 存檔 → 重開恢復」；資源不為負；人物不重複占用；月份只結算一次；戰鬥必定結束；完成與失敗均可繼續；無法僅靠重開畫面領取重複獎勵。

### P1：人界前期
範圍：金丹、四種主傳承、區域建設、產業鏈、人才職位、市場、三個以上秘境與初步宗門互動。

驗收：四種開局皆能自給與推進；不同傳承有實際差異；至少兩條可行經營路線；委託與交易可協助資源短缺恢復；P0 存檔可遷移。

### P2：人界第一個正式完整版本
範圍：至化神、十九種建築目標、六至八個主要勢力、進階探索、聯盟與吞併、壽元及繼承、主要正式美術。

驗收：從開局可完整達到化神；勢力有可觀察的發展與有限資源；戰爭有預警；長期存檔能繼續；至少完成三種不同發展路線試玩，記錄時數、停滯點及重複操作並調整。八十小時目標未經驗證時不得宣稱已達成。

### P3：完整人界境界
範圍：煉虛至渡劫、對應新玩法與內容、飛升準備。必須加入實際系統差異，不能只補名稱與數字。

### P4：雙界經營
範圍：上界開局、繼任掌門、人界自主管理、跨界限制與弟子飛升。驗收兩界同步結算、角色唯一、資源不因切換複製，並驗證舊存檔升級。

各階段都需要可啟動版本、實際操作檢查與完成紀錄。尚未完成的功能不得以空按鈕冒充完成。不要一次要求產出全部內容。

## 19. 品質檢查與平衡

重要自動檢查：月份結算、材料扣除、建造完成、人物行程衝突、戰鬥終止、獎勵唯一性、存檔往返、版本遷移與隨機狀態恢復。

人工試玩：新手是否明白下一步、數值說明是否完整、長期操作是否繁瑣、不同流派是否可行、字體與圖片是否清晰、重要風險是否有預警。

記錄指標：各境界到達年月與操作時間、最大資源缺口、閒置月份、每月必須點擊次數、不同流派通關率與電腦宗門擴張速度。平衡變更記錄原因與對舊檔的影響。
